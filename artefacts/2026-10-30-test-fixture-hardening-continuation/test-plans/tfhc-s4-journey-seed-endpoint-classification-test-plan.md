## Unit Tests

### Classification artefact names all 5 endpoints with an explicit redundant/legitimate verdict for each

- **Verifies:** AC1
- **Precondition:** Classification artefact does not exist yet.
- **Action:** Once written, read the artefact's text and assert it contains all 5 endpoint names (`seed-approval-journey`, `seed-board-journey`, `seed-actr-s2-journey`, `seed-ppc-s5-journey`, `seed-journey-gate-session`), each paired with an explicit verdict word (`redundant` or `legitimate`/`legitimately different`) — not just the endpoint name mentioned in passing.
- **Expected result:** All 5 endpoints found, each with exactly one verdict stated.
- **Edge case:** Yes — a false pass would be an endpoint name mentioned (e.g. in a list of "endpoints considered") without an actual verdict attached; the test must distinguish "named" from "classified."

### If any endpoint is marked redundant, a correctly-sized fast-follow scope is named for it

- **Verifies:** AC2
- **Precondition:** Classification artefact exists (from AC1's test).
- **Action:** For each endpoint marked `redundant`, assert the artefact's fast-follow section names that specific endpoint, which other endpoint it is redundant with, and a caller count or caller list (not a vague "needs consolidation" sentence with no specifics).
- **Expected result:** Every redundant-marked endpoint has a correspondingly specific fast-follow entry. If zero endpoints are marked redundant, this test is skipped (trivially satisfied — see AC3's test instead).
- **Edge case:** Yes — this test must fail if a redundant verdict exists with no fast-follow entry, or with a fast-follow entry that only repeats "needs consolidation" without naming the other endpoint and caller count.

### If no endpoint is marked redundant, the artefact explicitly closes the question

- **Verifies:** AC3
- **Precondition:** Classification artefact exists; zero endpoints marked redundant (the alternate branch from AC2's test).
- **Action:** Assert the artefact contains an explicit closing statement (e.g. "no endpoint found redundant — no further action required") rather than silence on the point.
- **Expected result:** Explicit closing statement present when the redundant-count is zero.
- **Edge case:** No.
