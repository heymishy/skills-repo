Discovery: Interactive kanban boards

Featureinteractive-kanban-boards StageDiscovery Author@heymishy Last updated2026-07-24

Problem

The web UI has three kanban board routes today. The boards themselves are visually out of step with the rest of the platform's current design language. More importantly, the boards are read-only: an operator can see which stage a feature or story is in, but cannot act on that view.

Proposed change

Restyle the three board routes on the current design system, and make cards draggable between valid next-stage columns. A drag calls the exact same /api/board/journey/:id/advance endpoint the existing click-to-advance path already uses — same tenant-ownership and readiness checks, no new authorization surface.

Out of scope

  • Multi-card drag / bulk stage moves.
  • New board views beyond the existing three routes.
